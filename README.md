# Water Treatment Process

This repository implements embedded code to implement a water treatment process.

The development of this program is part of the curriculum for the [Cyberphysical Systems and Internet of Things]([https://sigarra.up.pt/feup/en/UCURR_GERAL.FICHA_UC_VIEW?pv_ocorrencia_id=560299])(https://sigarra.up.pt/feup/en/ucurr_geral.ficha_uc_view?pv_ocorrencia_id=560304)) course.
